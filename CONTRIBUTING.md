# Contributing

1. Fork and clone
2. `swift build` to verify
3. Branch, change, PR

Tracks must be public domain. Add them in `Sources/Data/TrackLibrary.swift`.

Use design tokens from `Sources/Theme/Theme.swift` for visual constants.

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
